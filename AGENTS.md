# CMMTools repository workflow

- For every owner-requested change in `thesfjksa/vidancee-direct-saas`, update the current project handoff in the same pull request. Record the change, verification, deployment state, and any follow-up.
- The owner grants standing authorization to push and merge these changes into `main`. Push the tested changes, open or update the pull request, wait for applicable CI, then merge it yourself and verify the result on `main`.
- Respect branch protection and required reviews. Resolve failing checks and conflicts within the change's scope. Report any blocker that prevents completion.
- Start with [the current project handoff](docs/PROJECT_HANDOFF_2026-11-07.md). Update this link when a newer handoff takes over.
