CMMTools

Share this AIVID tab

Read-only. No Playwright or automated controls.

This extension captures only the ordinary Microsoft Edge AIVID tab you selected. It never clicks, types, manipulates the AIVID page, or shares the Windows desktop.

Generate the code in Admin → Provider → AIVID → Windows Premium Studio → Pair Extension.

Open AIVID normally first. Click the CMMTools extension while its tab is selected.

Sharing automatically pauses when you switch to another tab, close AIVID, or the 2-hour pairing expires. The controller window must remain open. Screenshots update about every 2.5 seconds, not full-motion video.
