CMMTools managed Webshare connection

CMMTools Admin configures Webshare once. You do not enter an API key or proxy server details. Studio refreshes the managed settings through your signed-in CMMTools account before each new session, then selects the fastest working configured proxy.

Chrome applies routing to AIVID domains across this regular browser profile, including other AIVID tabs. Other domains use DIRECT while active, potentially bypassing a system proxy. External sign-in, CDN and media domains are not covered. This is not a device-wide VPN. Use a separate profile if you rely on another proxy.

Close Studio before changing this preference. Closing Studio restores browser routing. Proxy credentials are saved locally in trusted extension storage and can be inspected on your device; the Admin Webshare API key stays on the server. No direct fallback is used when the managed route is unavailable.
