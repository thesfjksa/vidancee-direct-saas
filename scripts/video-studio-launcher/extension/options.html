Automatic proxy connection

Bring your own HTTP, HTTPS or unauthenticated SOCKS5 proxy servers. When enabled, the launcher tests them before opening Studio and keeps the fastest working route for that session. No servers or subscription are included.

Measures response time to the public AIVID homepage, not video rendering speed or download bandwidth. Failed routes are excluded. There is no automatic direct fallback in proxy-only mode.

Chrome applies proxy settings to the regular browser profile. All AIVID tabs may use this route, including tabs opened outside Studio; other domains use DIRECT while it is active. External sign-in, CDN and media domains are not covered. This is not a device-wide VPN and does not change Incognito settings.

Use a separate browser profile if you already use a proxy. Credentials are saved locally in this browser profile, are not synced to your Google account or uploaded to CMMTools, and are supplied only to the matching configured proxy. Local storage is not an encrypted password vault. The proxy operator can see connection metadata.
