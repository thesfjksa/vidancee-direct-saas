Connecting to Windows browser…
This is a Windows-native remote webpage view, not a browser simulation. The address bar, desktop and other windows are not streamed.
No Windows browser is connected. Ask the CMMTools administrator to open AIVID in their dedicated Windows Edge window and start the CMMTools native helper.

Mouse clicks and text are sent as restricted native Windows input to the foreground AIVID browser viewport. No Playwright, CDP, page scripts, browser automation or AIVID login cookies are used. The administrator must complete login and verification manually. Native file chooser transfers and downloads are not yet integrated; this pilot covers clicking, typing, scrolling and form controls. Manual Generate costs are billed directly to the AIVID account, outside CMMTools wallets.
