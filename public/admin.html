Cloud storage (Cloudflare R2)

Primary storage for generated videos. Files stay private; customers watch and download through short-lived links after CMM Tools checks they own the video. Works with any S3-compatible bucket (Cloudflare R2, Backblaze B2, Wasabi, AWS S3).

Checking cloud storage...

Bucket and API token

Cloudflare dashboard → R2 → create a bucket, then Manage R2 API Tokens → create a token with Object Read & Write for that bucket. The S3 endpoint is shown on the bucket's Settings page. Saving tests the bucket first; the secret is encrypted and never shown again.

Turn on direct browser uploads

Customers' reference videos upload straight to the bucket, so large files don't time out on the web host. The API token could not add the bucket's CORS rule itself. In Cloudflare open the bucket → Settings → CORS Policy → Add CORS policy, paste this, save, then click Test and save here again (or just leave it: uploads still work, through the web host).


      

    

    

      
Google Drive video storage
Keep generated videos private in your connected Google Drive account. Customers still watch and download videos using CMM Tools authenticated links.

      
Checking Google Drive...

      

        
Google OAuth credentials

        
Copy these two values from Google Cloud → Google Auth Platform → Clients. The secret is encrypted in the database and is never shown again after you save it.

        

        

        

          
          
        

      

      

        
        
        
      

      

      
Setup: Enable Google Drive API in Google Cloud, create an OAuth 2.0 Web client, and add https://cmmtools.site/admin/google-drive/callback as its exact redirect URI. Enter and save the Client ID and Secret above, then click Connect Google Drive. No Hostinger environment variables are needed for Google OAuth.

      
Connecting enables Google Drive for new videos and starts the background migration on the worker. MySQL chunks are deleted only after Google verifies each uploaded file. Images, reference media, and credit records remain in MySQL. Google Drive must have sufficient free capacity.
