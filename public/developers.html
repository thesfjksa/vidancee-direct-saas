Quick start

  1. Create a key and save it as CMM_API_KEY on your server.
  2. Choose a model from GET /v1/models.
  3. Create a generation with a unique Idempotency-Key.
  4. Poll every 5–10 seconds until completed or failed, then download the output.

Image creation is asynchronous too: a successful submission returns HTTP 202 and a job ID. The API uses CMM Tools model IDs and is not a drop-in OpenAI SDK replacement.

API reference


References & uploads
Send files as multipart/form-data. Available reference types and roles are returned in each model’s capabilities.
File fields: images, videos, audios. Use JSON arrays in referenceOrder, videoRoles and audioRoles when the model requires roles. Upload limits: 10 MB per image, 25 MB per video, 15 MB per audio, 24 files and 100 MB combined. A model may impose lower limits. JSON reference URLs are not supported.


Pricing & account access
Website and API generations draw from the same credit balance, with your account’s existing prices and simultaneous generation limit.
Use a quote before submitting. Admin model access and availability apply to both the studio and API.
A quote does not reserve funds. Credits are reserved when a job is created.
