Your Windows RDP and Microsoft Edge — no Browserless. This viewer uses an independently authenticated Apache Guacamole connection. Sign in using your assigned Guacamole account, then connect to your isolated Windows desktop. Google sign-in and CAPTCHA prompts occur inside the real Windows Edge browser. Completing a CAPTCHA manually may still be necessary.
1 · Upload image, video or audio references

Inside the desktop, press Ctrl + Alt + Shift for the Guacamole menu (or swipe from the left on touchscreens), open the shared drive and select Upload Files. The files appear in the Guacamole virtual drive inside Windows; choose them using the AIVID upload control.

2 · Generate video

Work inside Microsoft Edge as usual. This interactive session uses the provider account signed in on that Windows desktop. Video generation is billed directly by AIVID; no CMMTools wallet credits are deducted here.

3 · Download finished video

Save the completed video to the redirected Guacamole drive in Windows. In the Guacamole menu, open the shared drive and select the file to download it to your device. Files placed in the drive's Download folder may start a browser download automatically.
