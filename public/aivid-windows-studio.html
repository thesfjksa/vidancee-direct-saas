No Playwright. No remote browser automation. The owner opens AIVID manually in normal Microsoft Edge on Windows RDP, then shares the selected AIVID tab with the CMMTools extension. This viewer never clicks, types, launches Edge, or injects scripts. It displays periodic screenshots, not full-frame-rate video.

No shared AIVID tab yet. Open AIVID normally in Edge, pair the CMMTools extension through Admin, and start sharing.

Sharing pauses when the owner switches away from AIVID, closes the selected tab, stops sharing, or when pairing expires. Open Admin → Provider → AIVID to control access.

Privacy: Screenshots may reveal AIVID account information and prompts. Sign-in, CAPTCHA, Generate, reference uploads, and downloads are performed manually in Edge. The CMMTools viewer is read-only.
