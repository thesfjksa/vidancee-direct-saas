# Sluice: Seedance Lite

Seedance 2.5, 2.0 and 2.0 Fast "Lite" run on Sluice (https://www.getsluice.com).

- Setup: create a key in Sluice (raise its monthly spend cap, the default is $50), paste it in Admin → Providers → Sluice, then press Sync models.
- Pricing: at cost, 6,720 credits per USD (24 credits per rupee), plus $0.10 when any reference image is sent. The plan price gives the 50% margin.
- Limits: 3 jobs at once per key. Seedance 2.5 is 15–30 s; 2.0 and 2.0 Fast are 4–15 s at 720p. There is no generated audio, and aspect ratio is passed as a prompt hint.
- Failed or canceled jobs are refunded by Sluice and to the customer.
