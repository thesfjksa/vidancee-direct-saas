# Publish the Admin-managed Webshare launcher

Current package: public/downloads/CMMTools_Video_Studio_Chrome_Store_v1.7.0.zip. Rebuild with python3 scripts/package-chrome-store.py. Existing release ZIPs remain unchanged. Manifest is at the archive root; bundled logo artwork is reused from the original manual release.

1. Deploy the web app first, including Admin settings, public privacy policy and authenticated connection handoff described in EXTENSION_PROXY_SETUP.md.
2. In the existing Chrome Web Store developer item, upload v1.7.0 as a new package. Do not create a separate item for each version. If an older upload is already under review, use the dashboard's normal update/resubmission workflow.
3. Name: CMMTools Video Studio Launcher. Summary: Launch AIVID with display preferences and an optional Webshare proxy connection managed by CMMTools Admin.
4. Description: Open AIVID in a separate studio window. Customize display preferences and optionally use a Webshare connection configured by CMMTools Admin. Customers sign in to CMMTools to receive the managed connection and use their own AIVID accounts for generation. No generation credits or device-wide VPN are included. AIVID domain routing applies across the regular browser profile, not only the popup. Review connection scope in Options before enabling it.
5. Choose Unlisted for direct-link installation without search discovery. This is not account access control. Complete icon, genuine screenshots, support contact and developer details required by the dashboard. Privacy policy: https://cmmtools.site/extension/privacy.
6. Explain optional proxy, webRequest and webRequestAuthProvider permissions using EXTENSION_PROXY_SETUP.md. No Webshare API host permission is requested by this extension. Disclose locally stored proxy credentials, server-managed configuration and transmission to the proxy operator. All executable code is bundled; the PAC is generated locally from validated endpoints.
7. Submit for Google review and address findings. After publication, set the real 32-letter CHROME_WEB_STORE_EXTENSION_ID in the web app, then verify Add to Chrome installation. Merge does not publish or deploy the code.
8. Test normal Chrome and Edge: store install/confirmation, Options consent, CMMTools connection sign-in, proxy selection, AIVID own-account login, route indicator, closing Studio restoration and duplicate-free migration from an unpacked installation. Store and unpacked IDs/settings do not automatically transfer.

Owner account access, required artwork/contact information, actual Webshare API credentials, Google approval and production browser acceptance remain outside the completed local tests. No developer-account payment, publisher agreement, store submission, proxy purchase or paid generation was performed by the assistant.
