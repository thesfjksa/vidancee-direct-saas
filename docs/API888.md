# 888API integration

Source: https://888api.xin/docs · Pull request #20.

## Setup
1. Merge only after review and passing tests.
2. Manually redeploy web + worker in Hostinger; both share the MySQL settings table.
3. In Admin → Providers → 888API, save your token. Never paste it into GitHub, browser JavaScript or chat. Token stored AES-256-GCM encrypted.
4. Check key, then click “Import all accessible models”. The live account-scoped `GET /v1/models` is authoritative. Bundled documentation snapshot stays unavailable until live sync succeeds. Unrecognized account models are retained in Admin as unrunnable inventory entries.
5. Billing for **888API only**: upstream documented prices are in **CNY**; convert to actual USD with the Admin setting **1 USD = N CNY** (initial reference 6.6702 on 23 Oct 2026; update it when exchange rates change). Record provider consumption in USD. Charge customers **3.5× that USD consumption**, expressed in CMM credits using the existing 6,720 credits/USD conversion. Formula: `ceil((provider CNY / USD-CNY rate) × 3.5 × CREDITS_PER_USD)`. For a flat-price generation at ¥1.10 and reference rate 6.6702, the source cost is ~$0.164913 and customer cost is 3,879 credits. Existing providers keep their pricing.
6. Turn the 888API provider on *only after staging verification*. User-specific source switches can disable access.
7. When a model's input contract or pricing is unverified, it stays `adapterSupported=false` and cannot be used for paid generation.

## Implemented
- Safe authenticated catalog sync and bundled source inventory; no API key is exposed in client responses.
- Model-specific metadata for documented image and supported image-reference video SKUs; unreviewed SKUs kept disabled.
- Seedance video POST `/v1/videos`, durable task id, GET polling (no automatic paid POST retries), complete-file download into DB-backed user protected storage, interrupted/failed job refunds.
- GPT Image text-to-image on `/v1/images/generations`. Image edits via `/v1/images/edits` are **not** enabled; image reference controls are intentionally disabled.
- Customer/video model catalog, cost endpoint, account access, per-user credit reservations and worker processing.
- Pricing metadata in CNY is converted to **USD** before saving provider consumption. Customer credits are **3.5× USD cost** only for 888API. Flat CNY jobs stay flat regardless of duration; per-second jobs use duration before FX.
- Persistent jobs and two Hostinger apps; no production deployment performed by the PR.

## Validation required before production
- Run `npm test` and node syntax checks for changed files; check worker health after staging deployment.
- Test mocked provider responses for submissions, output redirects, failures, and restart recovery.
- Verify **every published price** and its duration/format limits against the current account-specific rates; the bundled snapshot can be stale and is not a source of account entitlement.
- One explicitly approved low-cost generation each for supported video and image formats with a funded token. Test image reference upload and multipart edits separately before enabling.
- Confirm wallet refunds, reconciliation of ambiguous paid submissions, and that temporary provider URLs are never returned to customers.

NOTE: This branch is not automatically deployed. Production remains unchanged until approved merge and both manual redeploys.
