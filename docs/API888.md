# 888API integration (catalog stage)

Branch: `feature/888api-integration` (not deployed).

Official documentation: https://888api.xin/docs

## Implemented
- 888API token encrypted in the shared `app_settings` table, with blank=keep and explicit clear.
- Admin provider card with a token check and a read-only GET `https://888api.xin/v1/models` catalog import.
- Models synced into `provider_models` with distinct `api888_` IDs. The full account-visible catalog is imported, including new IDs not in the bundled documented list.
- If the remote catalog is unavailable or returns no models, existing rows are preserved.
- An initial list of documented video/image IDs is seeded as an Admin-only snapshot. It does not prove the account can use them.
- Published CNY cost information is recorded where documented, never treated as USD.
